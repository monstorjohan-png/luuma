# LUUMA — موقع المطعم (نسخة عرض)

موقع كامل (عربي + إنجليزي) لمطعم **LUUMA · لوما** — الزمالك، القاهرة.
مبني بـ HTML/CSS/JS خالص: سريع، متوافق مع الجوال، مناسب لـ SEO، ويعمل على أي استضافة ثابتة **مجانًا للأبد**.

---

## 1) ما الموجود في المجلد

```
luuma-website/
├─ index.html            الصفحة العربية (RTL)
├─ en.html               الصفحة الإنجليزية (LTR)
├─ assets/
│  ├─ css/style.css      التنسيق الكامل
│  ├─ js/main.js         التفاعلات + إرسال الحجز لواتساب

├─ robots.txt
├─ sitemap.xml
├─ README.md             هذا الملف
└─ pitch.md              رسالة التواصل مع صاحب المطعم + العرض المالي
```

افتح `index.html` مباشرة في المتصفح (دبل كليك). لا يحتاج أي خادم.

## 3) النشر — استضافة مجانية دائمة وقوية

### الخيار الأسرع: Netlify Drop (مجاني)
1. افتح `https://app.netlify.com/drop`
2. اسحب **مجلد** `luuma-website` كاملًا إلى الصفحة.
3. يظهر رابط مباشر مثل `https://luuma-zamalek.netlify.app` خلال ثوانٍ.
4. أنشئ حسابًا مجانيًا لتثبيت الموقع (Deploy → Claim) فيبقى دائمًا.

### الخيار الأقوى لـ SEO: GitHub Pages (مجاني للأبد)
1. أنشئ حساب على `github.com` ومستودعًا جديدًا باسم `luuma-website`.
2. `Add file → Upload files` وارفع محتويات المجلد (بدون الحاجة لـ git).
3. `Settings → Pages → Source: Deploy from a branch → main / (root) → Save`.
4. يعمل الموقع على `https://<اسمك>.github.io/luuma-website/`.

> ملاحظة: الجهاز لا يحتوي على `git`، لذا الطريقة أعلاه عبر المتصفح هي الأنسب.

### الخيار الاحترافي: Cloudflare Pages (مجاني، نطاق ترددي غير محدود)
1. `dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets`.
2. ارفع المجلد واحصل على رابط `https://luuma-xxx.pages.dev`.

## 4) الدومين — الحقيقة باختصار

| النوع | مجاني؟ | دائم؟ | الملاحظة |
|---|---|---|---|
| دومين فرعي (`luuma.netlify.app` / `github.io`) | ✅ نعم | ✅ نعم | مجاني للأبد طالما الحساب موجود |
| دومين خاص (`luuma.com`) | ❌ لا | ✅ نعم | ~10–14$ سنويًا (أرخص وأكثر احترافية) |
| `luuma.eu.org` أو `luuma.pp.ua` | ✅ نعم | ~ | دومين فعلي مجاني، لكن التسجيل يتطلب موافقة وقد يتأخر/يُرفض |

**الخلاصة الصادقة:** لا يوجد "دومين خاص تمامًا ومجاني ودائم" بشكل موثوق. الاستضافة **مجانية ودائمة 100%**، أما الدومين الخاص فتكلفته رمزية سنويًا. الموقع جاهز لربط أي دومين في خطوة واحدة.

**ربط دومين مدفوع:** من لوحة Netlify/Cloudflare → `Domain settings → Add custom domain` → أضف سجلي DNS الذي يظهر لك عند مسجّل الدومين.
